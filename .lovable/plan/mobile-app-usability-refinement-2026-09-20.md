# Mobile app usability refinement

## Goal
Make Control Center, Attendance, Employee/Candidate, Client/Organization, and related screens consistently compact, readable, and easy to operate on phones.

## Work
- Audit shared page shells and every named workflow for double gutters, clipping, oversized controls, crowded actions, and dense data.
- Apply the existing dock-aligned mobile width and compact iOS-style controls consistently.
- Convert problematic mobile rows and tables into scroll-safe or stacked presentations while retaining complete desktop views.
- Improve form and dialog action placement, safe-area spacing, and useful glass surfaces without changing business rules.
- Preserve RBAC, attendance scope, calculations, workflows, production data, and native push behavior.

## Validation
- Check representative 320px, 393px, and 430px layouts where authentication permits.
- Run TypeScript and formatting validation.
