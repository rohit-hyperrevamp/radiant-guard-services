# Dashboard card consistency and More blur

- Give every dashboard summary card the same fixed mobile and desktop height, inner spacing, corner radius, label position, value baseline, and icon size.
- Align special cards such as contracts, UAN, contract follow-up, status totals, and operational insights to the same card frame.
